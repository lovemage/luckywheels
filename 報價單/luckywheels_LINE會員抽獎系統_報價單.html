現況判斷：目前為 React/Vite 前端展示版，正式版需補後端、資料庫與部署環境

重要安全原則：抽獎結果一定由後端 API 在資料庫 transaction 內決定，前端只負責播放輪盤動畫與顯示結果。正式版不會讓前端以 Math.random 或可被修改的程式碼決定中獎結果，避免使用者改程式碼作弊。

專案現況與技術判斷

目前已具備：

  • 紫金色幸運輪盤前端展示介面
  • 會員卡、點數、抽獎次數、底部選單
  • 排行榜、活動規則、我的獎品展示
  • Admin Console 前端假資料展示
  • 獎品名稱、庫存、權重、圖片預覽的展示邏輯

正式上線需新增：

  • LINE Login / LIFF 串接與會員資料寫入
  • PostgreSQL / Prisma 或等效資料庫 schema
  • 抽獎 API、庫存扣除、抽獎紀錄與領獎狀態
  • Admin 權限、搜尋、調整次數、獎品 CRUD
  • 兩套 domain / 兩套資料庫隔離部署

一、會員端功能範圍

項次功能項目備註
01LINE 登入 / 註冊
串接 LINE Login 或 LIFF，取得 LINE userId、名稱、頭像並建立會員。		包含於開發費
02會員資訊顯示
顯示會員名稱、頭像、VIP 等級與可抽獎次數。		包含於開發費
03點擊抽獎與抽獎動畫
前端呼叫後端抽獎 API，後端回傳獎品結果後，前端依指定獎項播放輪盤停止動畫。		包含於開發費
04中獎彈窗與我的獎品
中獎後顯示彈窗，會員可查看待領取、已領取、作廢等獎品紀錄。		包含於開發費
05活動規則
顯示抽獎規則、領獎說明與注意事項。		包含於開發費
06排行榜（若需要）
可依抽獎次數或中獎次數顯示排名；若不需要可保留現有展示頁或隱藏。		包含於開發費

二、Admin 後台功能範圍

項次功能項目備註
01LINE 會員列表與搜尋
查看 LINE 會員列表，支援名稱、LINE userId、手機、備註搜尋。		包含於開發費
02手動加值 / 扣除 / 調整抽獎次數
Admin 可幫會員增加、扣除或調整抽獎次數；需建立流水紀錄與操作原因。		包含於開發費
03會員抽獎紀錄
查看會員每次抽獎時間、抽中獎品、消耗次數、抽獎前後餘額。		包含於開發費
04獎品新增 / 編輯
設定獎品名稱、數量 / 庫存、中獎機率、啟用 / 停用。		包含於開發費
05獎品去背圖上傳
支援 PNG / WebP 圖片上傳與前台 object-fit 顯示；正式儲存可使用伺服器或雲端物件儲存。		包含於開發費
06所有中獎紀錄與獎品狀態
查看所有中獎紀錄，手動標記待領取、已領取、作廢。		包含於開發費
