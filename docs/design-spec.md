# 幸運輪盤設計規範

## 目標

本專案是 LINE 會員抽獎活動頁，目標視覺需接近參考圖的紫金色高級抽獎風格。前台優先服務手機使用者，畫面需讓業主一眼看出「幸運輪盤、會員可抽獎、點擊抽獎、查看獎品」四件事。

目前前台展示版以 `430x932` 手機比例為主要設計基準，桌面環境則同時展示手機前台與 Admin 後台。

## 視覺方向

- 主題：高級感、熱鬧、活動感、紫金色抽獎遊戲。
- 主色：深紫、亮紫、金色、洋紅緞帶。
- 質感：bitmap 3D 元件優先，避免只用 CSS/SVG 畫出扁平感。
- 氣氛：舞台光、金幣、紙花、發光燈泡、金色金屬邊框。
- 文字：所有可變文字盡量用 HTML/CSS 呈現，避免圖片文字在後台改獎品時失效。

## 目前使用圖資

固定圖資放在：

```text
public/assets/
```

主要資產：

```text
public/assets/lucky-bg.png          手機背景，紫色舞台與金幣紙花
public/assets/wheel-frame.png       金色輪盤外框、燈泡、上方指針
public/assets/logo.png              左上幸運輪盤 logo
public/assets/cta-button.png        目前保留但未作為主 CTA，因質感不夠理想
```

目前下方「立即抽獎」按鈕改回 CSS 製作，因生成圖底座的高光壓到文字，不適合直接使用。

## 手機頁面區塊

### 1. 背景

背景使用 `lucky-bg.png` 滿版覆蓋手機容器。

規範：

- 背景應保留中間輪盤區的可讀性。
- 金幣與紙花可出現在邊緣，但不可遮擋主 CTA、底部選單、會員面板。
- 底部舞台地板需保留，增加接近原圖的場景感。

### 2. 左上 Logo

使用：

```text
public/assets/logo.png
```

規範：

- Logo 位置在左上。
- 不要用程式重畫 logo。
- Logo 不可壓到右上會員面板。
- Logo 圖片本身包含皇冠、主標、緞帶副標。

### 3. 會員面板

位置：右上。

內容：

- 會員頭像
- 會員專區
- LINE 會員名稱
- VIP 等級
- 點數餘額
- 可抽獎次數

規範：

- 面板不得擋住輪盤主要獎品區。
- 手機版面板寬度目前約 `144px`。
- 背景為半透明紫色玻璃感，但不可過度模糊。
- 點數與次數需高對比可讀。

### 4. 輪盤

輪盤由兩層組成：

```text
外框：public/assets/wheel-frame.png
內盤：CSS conic-gradient 動態扇形
```

規範：

- 外框、燈泡、指針固定不動。
- 只有內盤與獎品內容旋轉。
- 中央旋鈕為 `50x50`。
- 中央旋鈕不放中文字。
- 中央旋鈕可點擊，觸發抽獎。
- 獎品內容需保留足夠面積，不可貼到外框。
- 輪盤每個位置的獎品、排序與機率需由 Admin 控制，前端不可寫死。

### 5. 輪盤獎品內容

每格顯示：

- 獎項等級，例如 `頭獎`
- 獎品名稱，例如 `旗艦手機`
- 獎品描述，例如 `Grand Prize`
- 獎品圖示或 Admin 上傳圖片

規範：

- 獎品文字保持可讀，不做整段倒置。
- 內容需往輪盤內側收，避免被外框吃掉。
- 獎品圖建議使用去背 PNG。
- 後台上傳圖需以 `object-fit: contain` 顯示。
- 中文文字以 2 至 4 字短詞最佳，過長文字需在後台限制或前端截斷。

### 6. 中央旋鈕

目前規格：

```text
width: 50px
height: 50px
文字：無
功能：可點擊抽獎
```

視覺：

- 金色圓形。
- 中央有小光點。
- 不放「立即抽獎」文字，避免與下方 CTA 重複。

### 7. 立即抽獎按鈕

位置：輪盤下方。

內容：

- 禮物 icon
- `立即抽獎`
- `消耗 1 次抽獎機會`

規範：

- 按鈕比原本縮小，避免壓縮輪盤空間。
- 金色膠囊造型。
- 文字必須清楚，不被高光壓住。
- disabled 狀態需變淡。

### 8. 底部選單

目前固定四個：

```text
輪盤
排行
規則
獎品
```

規範：

- 不放 Admin。
- Admin 後台只在桌面展示區或正式後台路由出現。
- 選中狀態為紫色亮面底。
- 每個按鈕需有 icon 與文字。

## 響應式規範

主要手機寬度：

```text
390px
430px
```

桌面展示：

- 左側顯示手機前台。
- 右側顯示 Admin Console。
- 手機容器維持接近真機比例，不拉寬。

## 動畫規範

抽獎動畫：

- 只有內盤旋轉。
- 外框燈泡、指針、背景、會員面板不旋轉。
- 旋轉時間由 Admin 設定，展示版目前約 `4.3s`。
- Admin 可設定旋轉秒數，例如 `3s`、`4.3s`、`6s`。
- 前端需依後端回傳或設定 API 套用旋轉時間，不可只寫死在 CSS。
- 使用 ease-out 類型減速。

Admin 可調整的輪盤視覺/行為設定：

```text
spinDurationMs       旋轉時間，單位毫秒
spinExtraTurns       額外旋轉圈數
spinEasing           旋轉 easing 名稱
wheelPrizeOrder      輪盤獎品位置排序
```

可點擊狀態：

- 中央旋鈕可觸發抽獎。
- 下方 CTA 可觸發抽獎。
- 抽獎中避免重複點擊。

無障礙：

- 支援 `prefers-reduced-motion`。
- 互動元素保留 focus-visible。

## 後續視覺優先事項

1. 重新生成更好的 CTA bitmap，要求文字區域完全空白且高光避開文字中心。
2. 生成更接近原圖的會員面板底圖，但仍保留文字用 HTML 顯示。
3. 生成獎品預設圖組，例如手機、耳機、禮券、咖啡、禮物、謝謝參加。
4. 若要更像原圖，輪盤內盤也可改為 bitmap 底圖，但需保留可動態替換獎品的文字層。
