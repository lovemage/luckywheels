駐守小卡

App 會讀出你目前坐的機台號，小卡直接顯示這台的數據，再推薦兩台空台；點一下，App 在遊戲裡幫你切過去。

  • 平常三行：目前機台、本場損益、兩台推薦
  • 點「更多」展開機台數據、綜合／精品兩榜與停損停利設定
  • 本場輸贏碰到停損、停利，手機震動並打開小卡提醒
  • 只提醒、不代按：不會自動轉、不會替你下注

Android App

版本 1.5.1 · 約 0.8 MB · Android 8.0 以上

下載安裝檔
  1. 下載安裝檔

    用手機 Chrome 開這一頁按下載。Chrome 提醒「檔案可能有害」時按仍要下載，Play 商店以外的安裝檔都會這樣提醒。

  2. 允許 Chrome 安裝

    第一次會被擋下來，按設定，打開「允許這個來源的應用程式」。只要設定一次。

  3. 安裝並開啟

    回到安裝畫面按安裝，完成後按開啟。已裝過舊版的直接覆蓋，不用先移除。

  4. LINE 登入、進入遊戲

    在 App 裡用 LINE 登入，按進入遊戲登入娛樂城。遊戲中點左側金色按鈕，就能喚出駐守小卡。

在 LINE 裡打開這頁的話，先點右上角選單「以預設瀏覽器開啟」再下載。完整安裝說明（含各品牌手機設定）

iPhone 網頁版

不用安裝 · Safari 開啟 · iPhone App 準備中

開啟網頁版

iPhone 目前使用網頁版：用 Safari 開啟、加入主畫面，之後就像 App 一樣從主畫面打開。遊戲在娛樂城另外開啟，兩邊切換使用。

  1. 用 Safari 開啟、LINE 登入

    在 Safari 網址列輸入 luckyds.com。從 LINE 收到連結時，點右上角「⋯」選在 Safari 中開啟，再按「用 LINE 登入」。

  2. 加入主畫面

    點 Safari 下方的分享按鈕，往下滑選加入主畫面，再按右上角「新增」。之後從主畫面的圖示直接打開。

  3. 開通、看數據

    首頁的曜金訊號不用開通就看得到；用輪盤積分開通後，還有精選空台房號、房間訊號與本金推薦。

  4. 入座後查房間訊號

    在娛樂城選好機台入座，回到助手首頁的房間訊號輸入房號。每轉結束後對照盤面，大圖數量剛好相等、寶石達到以上就是訊號達標，可買免遊；免遊結束後可按換下一組。網頁會記得房號與組數，來回切換不用重打。

網頁版讀不到遊戲畫面，所以房間訊號要自己對照；遊戲內浮窗、自動比對與震動提醒目前只有 Android App。iPhone App 推出後，安裝方式會放在這裡。

常見問題

需要另外註冊或付費嗎？

不用另外註冊，用 LINE 登入就好。數據助手用輪盤的會員積分兌換使用時間，不需要另外付費。

用了助手會比較容易中嗎？

不會。每一轉的結果都由遊戲伺服器決定，曜金只把已發生的機台紀錄整理、排序給你參考，不改變也不預測結果。請量力而為、先設好預算。

iPhone 可以用嗎？

可以，用網頁版：Safari 開啟 luckyds.com、LINE 登入，建議加入主畫面。房間訊號在網頁版要輸入房號查詢、自己對照盤面；遊戲內浮窗與自動提醒目前只有 Android App。

支援哪些遊戲？

目前支援 ATG 的戰神賽特 II。

安裝時跳出「檔案可能有害」怎麼辦？

這是 Chrome 對所有 Play 商店以外安裝檔的固定提醒，按「仍要下載」即可。請只從 luckyds.com 下載安裝檔。

娛樂城帳號會不會被助手拿走？

娛樂城是在娛樂城自己的頁面登入，助手不讀取、也不儲存你的娛樂城帳號密碼。App 只讀遊戲畫面上的機台號和點數，用來顯示數據和計算本場損益。
