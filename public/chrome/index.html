曜金數據助手

安裝電腦版（Chrome）

在電腦的 Chrome 裝上曜金數據助手，遊戲開在左邊、助手開在右邊的側邊欄。助手會讀遊戲畫面上的機台與點數，駐守小卡、守護與房間訊號都和 Android App 一樣

下載電腦版擴充功能

版本 1.0.0　·　約 25 KB　·　Google Chrome 116 以上（Windows／Mac）

請用電腦的 Google Chrome 開啟這一頁
手機請改用 Android App，iPhone 請使用網頁版

  1. 下載並解壓縮

    按上方「下載電腦版擴充功能」，下載完成後把 luckyds-assistant-chrome.zip 解壓縮

    Windows：在檔案上按右鍵，選「解壓縮全部」；Mac：直接點兩下。解壓縮後會得到 luckyds-assistant-chrome 資料夾，請放在不會刪掉的地方（例如「文件」），Chrome 每次開啟都會從這個資料夾讀取

  2. 打開開發人員模式

    在 Chrome 網址列輸入 chrome://extensions 按 Enter，打開右上角的 開發人員模式

  3. 載入擴充功能

    按左上角的 載入未封裝項目，選擇剛才解壓縮出來的 luckyds-assistant-chrome 資料夾

    要選的是資料夾本身，不是裡面的檔案，也不是 zip 檔

  4. 固定到工具列

    按網址列右邊的 拼圖圖示，在「曜金數據助手」旁邊按 圖釘，金色星星圖示就會一直顯示在工具列上

  5. 打開助手、登入

    按工具列上的 金色星星，右邊會打開曜金數據助手的側邊欄

    這台電腦的 Chrome 已經登入過 luckyds.com 的話，會直接沿用同一個帳號，積分與開通時間都和手機上一樣。還沒登入時按 用 LINE 登入，會開一個新分頁登入，完成後側邊欄自動更新

  6. 進入遊戲

    按側邊欄上方的 開啟娛樂城（或助手底部的 進入遊戲），照平常的方式登入、進遊戲、入座

    側邊欄上方顯示 已連上遊戲 與目前的機台、點數，就表示助手讀得到遊戲畫面。駐守小卡會顯示目前機台的數據和推薦機台，按 前往 會自動切換到那一台，載入後按「開始遊戲」即可

    遊戲分頁要保持在畫面上（不要縮到最小或切到別的分頁），助手才能即時比對房間訊號

常見問題

有新版本怎麼更新？
重新下載 zip，解壓縮後覆蓋原本的 luckyds-assistant-chrome 資料夾，再到 chrome://extensions 在曜金數據助手上按重新載入（圓形箭頭）
側邊欄一直顯示「尚未偵測到遊戲分頁」
請確認已經進入遊戲畫面（不是娛樂城首頁或大廳），並在 chrome://extensions 確認曜金數據助手是開啟狀態
助手會自動幫我玩遊戲嗎？
不會。助手只讀遊戲畫面上的數字，並依你的點選切換機台，不會替你轉動或下注，所有遊戲操作都由你自己決定
可以用 Edge 或其他瀏覽器嗎？
目前只支援電腦版 Google Chrome。手機請使用 Android App 或網頁版
